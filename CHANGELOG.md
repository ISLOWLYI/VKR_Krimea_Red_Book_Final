# Журнал изменений


### Исправления ошибок
- **Безопасность**: Добавлено экранирование спецсимволов в поисковом запросе для предотвращения SQL-инъекций
- **Координаты**: Исправлена функция `getPlantBounds()` для корректной обработки Point и Polygon геометрий
- **Изображения**: Добавлен SVG placeholder для отсутствующих изображений растений
- **UX**: Добавлено закрытие модального окна по клавише Escape в демо-версии

### Улучшения
- **База данных**:
  - Добавлена колонка `search_vector` для полнотекстового поиска
  - Создан триггер автоматического обновления поискового вектора
  - Улучшен поиск с учётом весов русского и латинского названия
- **Поиск**: Реализован гибридный поиск (полнотекстовый + LIKE) с ранжированием результатов
- **Производительность**:
  - Добавлены .htaccess файлы для кэширования и gzip-сжатия
  - Оптимизированы SQL-запросы
- **Установка**: Добавлен скрипт автоматической установки `install.sh`

### Новые файлы
- `assets/images/placeholder.svg` - заглушка для отсутствующих изображений
- `server/.htaccess` - настройки CORS и безопасности для API
- `client/.htaccess` - настройки кэширования и сжатия для клиента
- `install.sh` - скрипт автоматической развёртывания
- `CHANGELOG.md` - журнал изменений


### Первоначальный релиз
- Трёхзвенная архитектура (клиент-сервер-БД)
- Интерактивная карта на Leaflet.js
- PostgreSQL + PostGIS для пространственных данных
- REST-like API на PHP
- 6 категорий природоохранного статуса
- Поиск растений по русскому и латинскому названию
- Визуализация ареалов произрастания
- Адаптивный дизайн
