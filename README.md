# Веб-ГИС "Красная книга Республики Крым"

Веб-ориентированная геоинформационная система для хранения и предоставления информации о растениях Красной книги Республики Крым.

## Описание проекта

Проект разработан в соответствии с требованиями выпускной квалификационной работы и предоставляет:

- **Интерактивную карту** Крыма с визуализацией ареалов произрастания краснокнижных растений
- **Поиск растений** по русскому и латинскому названию
- **Карточки растений** с подробной информацией: описание, статус, изображения
- **Категоризацию** по природоохранным статусам (6 категорий)
- **Послойную визуализацию** данных с цветовой индикацией статуса

## Архитектура системы

Система построена по трёхзвенной архитектуре "клиент-сервер":

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│   Клиентская    │────▶│   Серверная      │────▶│   База данных    │
│   часть         │◀────│   часть (PHP)    │◀────│   PostgreSQL     │
│   (Leaflet)     │     │   (API)          │     │   + PostGIS      │
└─────────────────┘     └──────────────────┘     └──────────────────┘
```

## Технологический стек

### Клиентская часть
- HTML5, CSS3, JavaScript (ES6+)
- Leaflet.js 1.9.4 - библиотека для интерактивных карт
- OpenStreetMap - базовая картографическая подложка

### Серверная часть
- PHP 7.4+
- PDO для работы с базой данных
- REST-like API для обмена данными

### База данных
- PostgreSQL 12+
- PostGIS 3+ для работы с пространственными данными
- Формат хранения: WGS84 (EPSG:4326)

### Стандарты
- OGC WMS/WFS принципы
- GeoJSON для обмена пространственными данными
- UTF-8 кодировка

## Установка и развёртывание

### Требования
- Веб-сервер (Apache/Nginx) с поддержкой PHP
- PostgreSQL 12+ с расширением PostGIS
- PHP 7.4+ с расширением PDO-PgSQL

### Шаг 1: Создание базы данных

```bash
# Создать базу данных
createdb -U postgres redbook_crimea

# Включить расширение PostGIS
psql -U postgres -d redbook_crimea -c "CREATE EXTENSION postgis;"

# Выполнить скрипт создания структуры и наполнения
psql -U postgres -d redbook_crimea -f database/schema.sql
```

### Шаг 2: Настройка серверной части

Отредактируйте файл `server/config.php` при необходимости:

```php
define('DB_HOST', 'localhost');
define('DB_PORT', '5432');
define('DB_NAME', 'redbook_crimea');
define('DB_USER', 'postgres');
define('DB_PASSWORD', 'ваш_пароль');
```

### Шаг 3: Развёртывание на веб-сервере

#### Вариант A: OpenServer (Windows)
1. Скопируйте папку `redbook-crimea` в директорию доменов OpenServer
2. Запустите сервер
3. Откройте в браузере `http://redbook-crimea/`

#### Вариант B: Apache/Linux
```bash
# Скопировать файлы в директорию веб-сервера
sudo cp -r redbook-crimea /var/www/html/

# Настроить права доступа
sudo chown -R www-www-data /var/www/html/redbook-crimea
sudo chmod -R 755 /var/www/html/redbook-crimea
```

#### Вариант C: Встроенный PHP-сервер (для тестирования)
```bash
cd redbook-crimea
php -S localhost:8000
```
Откройте в браузере `http://localhost:8000/client/`
`http://localhost:8000/fix_db.php`

## API Документация

### Получить список всех растений
```
GET /server/api/plants.php?action=list
```

### Поиск растений
```
GET /server/api/plants.php?action=search&q=запрос
```

### Получить информацию о растении
```
GET /server/api/plants.php?action=get&id=1
```

### Получить пространственные данные (GeoJSON)
```
GET /server/api/plants.php?action=areas
```

### Получить список категорий статусов
```
GET /server/api/plants.php?action=statuses
```

## Категории статусов

| Код | Название | Цвет |
|-----|----------|------|
| 0 | Вероятно исчезнувшие | Тёмно-красный |
| 1 | Находящиеся под угрозой исчезновения | Красный |
| 2 | Сокращающиеся в численности | Оранжевый |
| 3 | Редкие | Жёлтый |
| 4 | Неопределённые по статусу | Светло-жёлтый |
| 5 | Восстанавливаемые | Зелёный |
